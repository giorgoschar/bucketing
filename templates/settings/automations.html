Set up the Apple Pay Shortcut

Every Apple Pay purchase on your iPhone becomes an expense here, paid by you.

Ingest URL

{{ ingest_url }}
  1. Create a token above and copy it.
  2. Open the Shortcuts app → Automation tab → + (New Automation).
  3. Choose Transaction (shown as Wallet on some iOS versions).
  4. Choose the cards to watch (your Apple Pay cards), leave the other options as they are.
  5. Select Run Immediately (and turn off “Notify When Run” if you like), then Next → New Blank Automation.
  6. Add the action Get Contents of URL and set:
    • URL: the ingest URL above
    • Method: POST
    • Headers: Authorization = Bearer <your token>
    • Request Body: JSON with the keys merchant = Shortcut Input → Merchant, amount = Shortcut Input → Amount, card = Shortcut Input → Card (all as Text).
  7. Tap Done. Pay with Apple Pay once and check that the expense appears — you also get a notification so you can fix the category or bucket.

Ask for a category

Optional. The purchase is saved first; when none of your rules knows the merchant, the Shortcut can then ask you for the category. Add these actions after Get Contents of URL:

  1. Get Dictionary Value: get the value for category_names in Contents of URL. The reply has this list only when the purchase still needs a category (needs_category is then true).
  2. If Dictionary Value has any value:
    • Choose from List: choose from Dictionary Value (your category names).
    • Get Dictionary Value: get the value for id in Contents of URL.
    • A second Get Contents of URL: URL {{ ingest_url }}/Dictionary Value/classify (the id from the step before), Method POST, the same Authorization header, Request Body JSON with category = Chosen Item (Text) and remember = true (Boolean).
  3. End If.

With remember on, the merchant gets a rule, so you are asked once per merchant. To pick the bucket too, do the same with bucket_names and send bucket = the chosen name. It works for 15 minutes after the purchase, and only with the token that added it.

Known iOS flakiness: Transaction automations sometimes time out or fire twice (a long-standing issue reported on Apple’s developer forums), especially with a weak connection. If a purchase is missing, add it by hand.

Duplicates are merged for you: repeated requests for the same merchant and amount within the same minute are recognised server-side and create only one expense. A retry that crosses a minute boundary can create a second expense — just delete it. Expenses you deleted are not brought back by a retry.

Changing your password or resetting 2FA revokes your Shortcut tokens; create a new one afterwards.

Optional JSON keys: currency (defaults to {{ household.default_currency if household else 'the household currency' }}), occurred_at (ISO 8601 date-time), notes. The category comes from your auto-categorisation rules; the bucket is the token’s default, otherwise your first day-to-day bucket.
