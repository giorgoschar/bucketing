{# Server-rendered SVG charts. Deliberately not a JavaScript charting library. These live inside #insights-body, which is replaced wholesale on every filter change, so a JS chart would have to be torn down and re-instantiated on each swap — the same lifecycle problem that repeatedly broke the Alpine components here. SVG from the server has no lifecycle, needs no CDN, and works offline in the PWA. Hover/tap/focus values come from `data-tip`, read by a single delegated listener in static/chart-tooltip.js. That replaced SVG , whose native tooltip took about a second to appear and never showed on a phone. Every interactive shape is also tabbable and carries an aria-label, so the numbers are reachable by keyboard and screen reader too. Colours come through `currentColor` and Tailwind classes so light/dark mode follow the rest of the UI for free. #} {# --------------------------------------------------------------------------- Line + area chart, for a value over time. points: [{label, total}], newest last. --------------------------------------------------------------------------- #} {% macro line_chart(points, currency='EUR', height=140, id='') %} {% set W = 560 %} {% set H = height %} {% set PAD_L = 4 %} {% set PAD_B = 18 %} {% set vals = points | map(attribute='total') | list %} {% set vmax = vals | max if vals else 0 %} {% set top = vmax if vmax > 0 else 1 %} {% set n = points | length %} {# No preserveAspectRatio override: "none" stretches text and squashes the point markers into ellipses when the SVG is wider than its viewBox. #} <svg viewBox="0 0 {{ W }} {{ H }}" class="w-full h-auto" role="img" aria-label="Spending over time"> {# horizontal guides at 0/50/100% of the peak #} {% for frac in [0, 0.5, 1] %} {% set y = PAD_B + (H - PAD_L * 2) / (n - 1) %} {% set coords = [] %} {% for p in points %} {% set x = PAD_L + step * loop.index0 %} {% set y = (H - PAD_B) - (H - PAD_B - 8) * (p.total / top) %} {% set _ = coords.append((x, y)) %} {% endfor %} <polygon class="fill-primary-500/10" points="{{ coords[0][0] }},{{ H -
