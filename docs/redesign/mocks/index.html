Redesign brief · 6 Oct 2026

Tameio: the household money app, rebuilt around five places.

A from-scratch redesign based only on what the current app does. Pick a direction and light or dark at the top; every screen page follows your choice. All figures are sample data for a two-person household in Kifisia.

≈45 mobile screens4 desktop screens3 visual directionsSettle up removed
Platform
React PWA, installed on the iPhone home screen

A native iOS build without the $99 developer account has to be re-signed every 7 days. A PWA never expires and still covers what the app uses:

  • Face ID sign-in with passkeys (WebAuthn)
  • Camera QR scanning
  • Web push (iOS 16.4+)
  • Offline queue

Suggested stack: Vite, React, TanStack Router and Query, with the FastAPI JSON API behind it. Types and tokens can later move to Expo unchanged.

Scope
Everything stays except settle up
  • Expenses, income, budgets, bills, insights, search
  • Cash stash and wallets
  • Pantry and shopping
  • Receipt scanning, Apple Pay Shortcut

Payer and per-person shares stay, so "paid out vs my share" still works. Balances, transfers and settlement history are gone.

Navigation
10 sidebar areas become 5 tabs

Home · Activity · Add · Plan · Insights. Settings sits behind your avatar. The old app hid Settle up, Cash and Search on mobile; now every feature is at most two taps away.

Backend work for a React client

API gaps to close

The JSON API under /api/v1 covers about two thirds of this design. These endpoints are missing today.

Activity

  • Full-text search with all filters
  • Duplicate groups and "keep both"
  • Bulk update (payer, category, budget)
  • Check for a duplicate before saving
  • Export

Home & Insights

  • A "needs you" feed that collects every issue type
  • Person lens (paid out vs my share)
  • Category and merchant drill-down
  • Fuel per car

Add & Scan

  • QR receipt lookup (/scan/qr)
  • Create and edit category rules
  • Offline client_id on every create

Plan

  • Bill history, set amount, pause and resume
  • Unarchive a budget
  • Pantry: settings, refresh price, archive, mark bought

Account

  • Passkeys (WebAuthn register and sign-in)
  • Listing and switching households under JWT
  • Invite accept, 2FA enrolment
  • Push subscribe with JWT

Remove

  • Settlement endpoints and the Settlement table
  • enable_settlement on buckets
  • exclude_from_settlement on expenses
