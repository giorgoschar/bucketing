01 · Access

Sign in with Face ID. The 6-digit code becomes the fallback.

Passkeys (WebAuthn) work in an installed iPhone PWA and already count as two factors, so the authenticator code is only needed on a new device without a passkey. Joining by invite folds account creation and security setup into one short path.

02 · Home

One number, then only what needs you.

The dashboard used to show nine blocks. Home now answers two questions: how much has gone out this month, and what needs fixing. Overdue bills, bills that need an amount, unlogged cash, expenses with no payer, possible duplicates and low pantry stock all go into one attention inbox.

03 · Activity

Search, list, fix: one screen.

Search, the transaction list, duplicates and bulk "set payer" used to be three pages. They are now one feed. Filters are chips, and problem filters ("No payer", "Possible duplicates") show their count, so cleanup starts from the same place you browse.
