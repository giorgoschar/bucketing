## Global Constraints

- **Migration:** exactly one, `e7f8a9b0c1d2`, revising `d6e7f8a9b0c1`. If the id is taken, pick another, keep one head, report it.
- **No number changes:** no figure, sentence or rule that exists today changes its meaning. Cards and rows move and merge; their content is what it was. Assert the old strings in the new places.
- **API compatibility:** existing JSON keys and types are unchanged; only additions.
- **Tests:** an existing test case may be changed only where the approved spec makes its assertion wrong by design (a card that moved tabs, a row count that went from 10 to 5, a chip that was removed). Change the smallest assertion that is wrong, never delete a case to get green, and list every changed case in the report with the spec section that requires it. Everything else in the suites passes untouched.
- **Phone layout rules:** every desktop CSS rule inside `@media (min-width: 1024px)`; no horizontal page scroll at 390×844 or 1440×900; 44 px targets on the phone; `.ui-num` in running text wraps.
- **Type sizes:** streams H, I, C and Q add no new `font-size` or `font-weight` values; reuse values already in the file they edit. Stream T introduces the tokens.
- **Copy:** verbatim from the spec.
- **Bundle:** `npm run build` must exit 0 (check the exit code, not the output); the main chunk stays under the 340 kB guard; new screens and the scanner are lazy.
- **Commits:** one per task, by explicit path. No pushing and no subagents.

## Review Focus

1. **Home with one attention row, and with none:** no expander, no "Show 0 more", and the first row keeps its filled button.
2. **A bill that is overdue, needs an amount and changed, where the user dismisses the change:** one row stays, with the right action, and the dismissal survives a reload.
3. **A deep link to an Insights card that moved** (a notification or a Home link that lands on `/insights` expecting Bills or Statements): the user reaches it without hunting; old links keep working.
4. **A merchant typed with different case, accents or spacing** ("LIDL", "Lidl ", "Λιντλ" vs "ΛΙΝΤΛ"): the suggestion, the rule and the composer's pre-selection agree with each other and with the server.
5. **Search input that is hostile or odd:** `%`, `_`, a 100-character string, Greek text, a barcode, fast typing that sends requests out of order (an old answer must not replace a newer one).

Each has a test in the task that owns it (H1, H1, I1, S1 and C3, S2 and Q1).
