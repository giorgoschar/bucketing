# Expenses v2: Audit Fixes + 5 Features — Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans (native, single session) — NOT subagent-driven. Steps use `- [ ]` checkboxes. First action: copy this file to `docs/superpowers/plans/2026-10-01-expenses-v2.md`, create branch `feat/v2`, commit. Work phases in order; each task ends with a green targeted test run and a commit. Run the full suite only at the end of each phase.

**Goal:** Harden and clean the existing FastAPI/HTMX/Alpine expenses app (hosted on Coolify), then add: correct "who paid" insights, payment method + cash ledger, Apple Pay ingest via iOS Shortcut, and a stock list with PosoKanei price tracking and shopping suggestions.

**Architecture:** Keep the existing shape (routers → `app/services*` → SQLAlchemy models, Jinja + HTMX partials, Alpine factories in `static/*.js` loaded from `<head>`). New domains get their own service module and router. One Alembic migration per phase. All money stays `Numeric`/`Decimal` until presentation.

**Tech stack:** Python 3.12, FastAPI 0.115→latest 0.115.x, SQLAlchemy 2, Alembic, Postgres 16 (SQLite in tests), Jinja2, HTMX, Alpine, Tailwind 3.4 (`npm run css`), APScheduler, httpx, PyJWT (replaces python-jose), cryptography (Fernet), pytest.

**Spec:** this document (sections "Audit findings" and "Feature specs" below are the spec).
